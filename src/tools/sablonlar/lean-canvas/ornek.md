# Lean Canvas: Demlik (ilk yıl) · Sürüm 3 · Şirketin ilk yılı

| Kutu | |
|---|---|
| 1. Problem (en önemli üç) | Sabah kuyruğu; siparişin yanlış çıkması; bağımsız dükkânların dijital sipariş alamaması |
| Mevcut alternatifler | Kuyrukta beklemek, dükkânı telefonla aramak, teslimat uygulamaları, zincirlerin kendi uygulamaları |
| 2. Müşteri segmenti | İki taraf: düzenli kahve içen müşteriler ve bağımsız kahve dükkânları |
| İlk benimseyenler | Ofis yoğun semtlerde sabah işe giden müşteriler; günde 30+ sipariş alan dükkânlar |
| 3. Benzersiz değer önerisi | Mahalle kahvecin, kuyruğa girmeden |
| 4. Çözüm | Önceden sipariş ve ödeme; dükkân için kasaya düşen sipariş ekranı |
| 5. Kanallar | Kasadaki QR kartı, arkadaş daveti, dükkân ziyaretleri |
| 6. Gelir akışları | Dükkândan aylık abonelik ve sipariş başına komisyon; müşteriden ücret yok |
| 7. Maliyet yapısı | Ödeme işlem ücretleri, altyapı, destek, maaşlar, dükkân satış ekibi |
| 8. Kilit metrikler | Haftalık tamamlanan sipariş; 30 günde ikinci sipariş; aktif dükkân |
| 9. Haksız avantaj | (İlk yıl boştu.) Bugün: kasa entegrasyonu ve iki taraflı ağ etkisi |

## En riskli varsayım

"Dükkânlar sipariş başına komisyon ödemeyi kabul eder." İlk 20 dükkânla ödeme yapan bir pilot yapıldı; 17'si üç ay sonra devam etti.
