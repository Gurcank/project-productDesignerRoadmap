# Retro — Sprint 13, Sipariş takımı

| | |
|---|---|
| Kolaylaştırıcı | Kaan |
| Süre | 60 dakika (15.30–16.30) |
| Format | Sailboat |
| Hedef | Sprintin bizi neyin ileri ittiğini, neyin geri çektiğini görmek |

## Önceki retronun eylemi

- "Daily'yi panonun üzerinden, bitmeye en yakın işten başlayarak yap" — sahibi Ece. **Yapıldı**; takım sürdürmeye karar verdi.

## 1. Ortamı hazırla (5 dk)

Retrospektifin temel kuralı okundu: herkes, o an bildikleriyle, becerileriyle ve elindeki imkânlarla yapabileceğinin en iyisini yaptı. Açılış: herkes sprinti tek kelimeyle anlattı.

## 2. Veri topla (15 dk) — Sailboat

| Rüzgâr (ileri itenler) | Çapa (geri çekenler) |
|---|---|
| Zeynep'in önceden yazdığı test senaryoları | Kasa tedarikçisinden habersiz gelen API değişiklikleri |
| Çarşamba odak zamanı | Daily'de 25 dakikaya uzayan iki gün |
| Selin'in boş ve hata durumlarını erken vermesi | Ödeme ekibinden geç gelen cevap |

## 3. İçgörü üret (15 dk)

En çok oy alan çapa: habersiz API değişiklikleri. 5 Neden ile kök neden: değişiklikler tedarikçiden Leyla'ya e-postayla geliyor, takıma ulaşmıyor.

## 4. Ne yapacağına karar ver (15 dk)

| Eylem | Sahip | Kontrol |
|---|---|---|
| Tedarikçinin API değişikliklerini her salı panoya işle | Ayşe | Sprint 14 sonu |
| Daily 15 dakikayı geçerse ayrıntıyı sonraya al | Kaan | Sprint 14 sonu |

## 5. Kapat (10 dk)

Eylemler tekrar okundu. Retro geri bildirimi (Artı / Delta): artı — "Sailboat konuşmayı açtı"; delta — "Veri toplamaya daha az süre".
