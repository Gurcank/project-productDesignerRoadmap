# İçgörü: Öğrenciler derse yetişemeyeceklerini düşündükleri sabah sipariş vermiyor

| Alan | |
|---|---|
| Olgu | Sekiz öğrenciden altısı dersten 10–15 dakika önce, yürürken sipariş veriyor. Günlük çalışmasında on kişiden yedisi geç kaldığı günlerde vazgeçti. |
| Önemi | Kampüste kaybedilen siparişin bir kısmı bekleme süresinin bilinmemesinden geliyor; hedef günde 600 sipariş. |
| Kanıt | "Kaç dakikada hazır olacağını bilsem sipariş verirdim, ama bilmiyorum, risk almıyorum." (K3) |
| Eylem | Hazırlık süresini sipariş ekranında göstermek (Elif refinement'a aldı). Yeni soru: yoğun dakikalarda tahmin ne kadar doğru tutar? |
| Kaynak | Kampüs görüşmeleri 1. tur ve günlük çalışması |
| Etiketler | kampüs, sabah, bekleme süresi |
