# Deney kartı: V2

| Alan | |
|---|---|
| Varsayım | Müşteri, ana ekrandaki "Son siparişini tekrarla" düğmesini fark eder. |
| Tür | Kullanılabilirlik |
| Önemi | Yüksek: düğme görülmezse özellik kullanılmaz |
| Eldeki kanıt | Yok |
| Test | Tıklanabilir prototip; görev: "Dünkü kahveni yeniden sipariş et." |
| Katılımcı ya da veri | 8 düzenli müşteri (Mert'in görüşme listesinden) |
| Başarı ölçütü (önceden) | 8'den en az 6'sı düğmeyi 10 saniye içinde bulur |
| Sahibi ve tarih | Selin ve Mert, sprint öncesi hafta |

## Sonuç

7/8 katılımcı düğmeyi 10 saniye içinde buldu. Bulamayan katılımcı önce menüye gitti; düğmeyi "kampanya" sandığını söyledi.

## Karar

Geçti. Selin düğmenin metnini sipariş içeriğiyle birlikte gösterecek ("Orta boy filtre kahve · Moda"), böylece kampanyaya benzemeyecek.
