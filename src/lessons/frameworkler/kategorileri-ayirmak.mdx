## Library ve framework

<Compare>
<Pane title="Library (kütüphane)">

- Sen onu çağırırsın
- Kontrol sende kalır
- Tarih biçimlendirme, grafik

</Pane>
<Pane title="Framework (çatı)">

- O seni çağırır, kurallarına uyarsın
- Kontrol tersine döner
- Dosya yapısı, yönlendirme, veri akışı hazır

</Pane>
</Compare>

**Library**, belirli bir işi yapmak için çağırdığın hazır kod paketidir. Bir tarih biçimlendirme ya da grafik kütüphanesi böyledir. "Bunun için ayrı bir kütüphane eklemeyelim; 20 satırla çözülüyor."

**Framework**, projenin yapısını ve akışını belirleyen, senin onun kurallarına uyduğun sistemdir. Karşılığında dosya yapısı, yönlendirme, veri akışı gibi kararları hazır verir; her projede aynı kararları yeniden vermezsin. "Framework'ün kurallarına uyalım; kendi yapımızı kurarsak ekosistemden faydalanamayız."

Not: React teknik olarak bir **kütüphanedir,** framework değil. Ama günlük konuşmada herkes framework der ve bu bir sorun değildir.

## Meta-framework

**Meta-framework**, bir UI kütüphanesinin (React, Vue, Svelte) üzerine kurulan ve eksik parçalarını tamamlayan üst katmandır. React tek başına yalnızca arayüz çizer; yönlendirme, sunucu tarafı işleme, veri çekme, build ve deploy kararlarını çözmez. Meta-framework bunların hepsini bir arada verir. Next.js, Nuxt, SvelteKit, Astro ve React Router v7 bu kategoridedir. Proje başlangıcının en kritik kararıdır: "React seçtik ama asıl karar meta-framework: Next.js mi React Router mı?"

## Runtime

**Runtime (çalışma ortamı)**, JavaScript kodunun fiilen çalıştığı ortamdır: tarayıcı, Node.js, Deno, Bun. JavaScript tarayıcı için tasarlanmıştı; Node.js onu sunucuda da çalıştırılabilir hâle getirdi ve ön yüz ile arka yüzün aynı dilde yazılabilmesini sağladı. "Edge runtime'da bazı Node API'leri çalışmıyor; o kodu ayrı bir yere alalım."

## Kendini yokla

<SelfCheck question="Library ile framework arasındaki fark nedir? React hangisidir?">

Library'de kontrol sendedir: sen onu çağırırsın. Framework'te kontrol tersine döner: o seni çağırır ve yapıyı o belirler. React teknik olarak bir kütüphanedir, ama günlük konuşmada herkes framework der.

</SelfCheck>

<SelfCheck question="Meta-framework neyi çözer? React tek başına neden yetmez?">

</SelfCheck>
