Git bilgisayarında çalışır; peki ekip nerede buluşur? Uzak depoda.

## Remote

**Remote (uzak depo)**, projenin senin bilgisayarının dışındaki kopyasıdır. **`origin`** senin kendi uzak deponun varsayılan adıdır; **`upstream`** ise fork yaptığın asıl deponun yaygın adıdır. Ekibin ortak buluşma noktasıdır: herkes kendi bilgisayarında çalışır, işini uzak depoya gönderir. "Upstream'den güncellemeleri çekip kendi fork'una aktar."

## Clone ve fork

**Clone**, uzak bir depoyu kendi bilgisayarına indirmektir ve günlük çalışmanın başlangıcıdır. **Fork**, o deponun kendi hesabın altında bağımsız bir kopyasını oluşturmaktır. Fork, yazma yetkin olmayan bir projeye katkı vermenin yoludur: kendi kopyanda değişiklik yapar, sonra asıl projeye pull request açarsın. Açık kaynağın çalışma biçimi budur. "Yazma yetkin yok; fork'la, değiştir, PR aç."

## Push, pull, fetch

- **Push:** yerel değişiklikleri uzak depoya gönderir.
- **Fetch:** uzaktaki değişiklikleri indirir ama birleştirmez.
- **Pull:** ikisini birden yapar: indirir ve birleştirir.

Fetch'in ayrı olması, "önce ne değişmiş bir bakayım" imkânı verir. "Push'lamadan önce pull al, yoksa reddedilir."

**Force push tehlikelidir:** uzaktaki geçmişi zorla üzerine yazar ve başkalarının işini silebilir. Paylaşılan dallarda kullanılmaz; ana dalda ise genelde dal koruması ile tamamen yasaklanır.

<Summary>

- Remote projenin uzak kopyasıdır; origin kendi deponun, upstream fork'un asıl deposunun adıdır.
- Clone depoyu indirir, fork kendi hesabın altında bağımsız kopya oluşturur.
- Push gönderir, fetch indirir, pull indirir ve birleştirir; force push başkalarının işini silebilir.
